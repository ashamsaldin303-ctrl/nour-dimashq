## Registry rules

1. **NEVER recreate an inventoried component.** Need a variation? Add a prop or a variant inside the existing file (and update the row above).
2. shadcn/ui primitives live in `src/components/ui/` (new-york) — CLI-installed, never hand-rolled copies.
3. **`ProofCard` is deliberately NOT in this registry**: it is defined locally inside `src/app/(ar)/ar/sold/page.tsx` (dated sold-proof card: PlaceholderTile + «تم البيع» chip + type·district + ref + «بيعت بـ … دولار» + sold date). The name stays reserved in case a shared extraction is ever needed — extract it here first if that happens.
4. wa.me CTAs never build their own links — always `waLink()` from `@/lib/wa` + `data-wa-property` / `data-wa-source` attributes for the analytics delegation.
