## 3. SAMPLE swap path — «مسار النشر» (listings data)

**ALL current listing data is SAMPLE** (8 seed rows + 1 agent, marked SAMPLE in `prisma/seed.ts` and here). Real listing data is the owner's decision before launch — never fabricate a listing, a price, a counter, or a testimonial.

### Step 1 — Edit the data
Either edit the rows in `prisma/seed.ts` (recommended — the file is the content-ops source of truth), or run SQL directly against the `Listing` table (`INSERT` / `UPDATE` / `DELETE` on `db/custom.db`). Field laws:
- `ref` unique, shape `^[A-Z]{3}-\d{4}-\d{3}$` (e.g. `APR-2026-118`) — the office quotes refs in conversation.
- `slug` unique; `district` ∈ `al-mezze | al-maliki | abu-rummaneh`; `type` from the Zod union in `src/lib/schemas.ts`; `status` ∈ `available | reserved | sold | rented`.
- `priceUsd` = whole dollars; `priceDate` = the day the price was confirmed («سعر اليوم؟» — the weekly ritual stamp); `negotiable` flag; **`priceSyp` is never rendered statically** (daily-rate law).
- Sold listings keep their **original price** and gain `soldDate` — they become dated proof cards in `/ar/sold` (never deleted, never hidden).

> Caveat: the seed's upserts are **create-only** (`update: {}` keyed on `ref`). New refs insert; existing refs are left untouched. To amend an existing ref, update the row via SQL or delete it first (`DELETE FROM Listing WHERE ref = '…'`), then re-seed.

### Step 2 — Apply
```bash
bun run db:push && bun prisma/seed.ts
```
`db:push` syncs the schema; the seed is idempotent (upserts by unique `ref`/`slug`).

### Step 3 — Real photos
Set each listing's `media` JSON items to real photo URLs — `/uploads/...` paths served from `public/` — with `kind: "photo" | "floorplan"` and **`is_ai: false` always**. The Zod `MediaItemSchema` (`src/lib/schemas.ts`) hard-refuses `is_ai: true`: AI imagery may never depict a listed property. Until real photos exist, any non-image `url` (e.g. `placeholder:al-mezze`) renders the mashrabiya motif `PlaceholderTile` automatically — district label + «صورة العقار قادمة» — with no code change.

### Step 4 — Verify
```bash
curl -s http://localhost:3000/ar/listings | grep APR-2026-118        # the ref appears in the index HTML
curl -s http://localhost:3000/ar/listings/apartment-mezze-apr-118 | grep APR-2026-118   # and on its PDP
```
Then spot-check in the browser: index card → PDP → sticky WhatsApp bar carries the new ref.
